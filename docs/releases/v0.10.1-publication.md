  emulator; the same original-key instrumentation APK seeded the actual old app's
  Room rows, likes/history/playlist, settings, saved queue, private WAV, MediaStore

  owner-user package UID and verified all those rows/files/source hashes. No
  uninstall, data clear/reset, hidden error or test retry was used. This is not a
  physical-phone/OEM pass.
- **Native:** all six hosts installed immutable Preview2, then the new installer
  over the old installed profile. The **new installed frozen executable** checked
  the normal user-data location: library/playlists/likes/history/settings/queue,
  private/device downloads, Studio sources/clips and actual preserved audio decode.
  Both Linux `.deb` and portable `.AppImage` replacement were exercised. This is
  disposable virtual-host fixture acceptance, not a physical-user data claim.
- The original Android certificate was preserved; no replacement production key
  was generated. The original protected identity signed the format2,
  domain-separated desktop manifest; the actual installed-client verifier checked
  all six targets/eight installer plans again before final publication.
- **Old empty-key PC previews need one manual install-over**, without uninstalling.
  The new pinned identity supports future verified, consent-based, OS/CPU/kind-
  correct in-app updates. Android's existing updater can use the common latest
  APK. Do not mix the installed Windows32/64 runtime profiles.
- Manifest signature verification is **not Windows Authenticode or Apple Developer
  ID/notarization**. Those OS publisher certificates remain unconfigured; do not
  bypass OS security warnings.
