## What remains unexecuted / unsupported
This is an **unsigned experimental desktop preview**, not production Authenticode/Apple notarization or full Android parity. Qt5.15.2 is a legacy compatibility UI. CI executes a real32-bit process on an x64 Windows host (**WoW64**), not physical32-bit Windows10 hardware/install-over/heard audio. Windows7/8 unsupported. Physical low-space/peripheral/live-provider/data-preserving installation/update acceptance remains open; [acceptance checklist](../PLATFORM_ACCEPTANCE.md). Linux baseline glibc2.39; macOS13+.

Production desktop trust keys/channel remain empty and reject untrusted updates. Desktop Listen Together, enhanced Android recommendation parity, optional video, timed lyrics, full EN/HI/OS-media integration remain open. No audio cloud/phone-to-PC sync; JSON transfers metadata, private preparation still uses disk. Do not disable OS security or uninstall/reset data to call acceptance passed.
